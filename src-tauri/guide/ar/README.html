Import guide

Add tasks, events, obligations, notes, habits and contacts in one go.

In short In this folder With Excel Columns Accepted values With a text file Calendars and contacts Preview and duplicates Good to know

1In short

1 Prepare Copy Aqueli template.xlsx out of this folder, then fill it in: one row per item.
2 Import Drop the file into Documents\Aqueli\Import, or drag it onto the Aqueli window.
3 Check Read the preview, then click “Import”. Ctrl+Z removes the whole import.

Aqueli spots a file dropped into the Import folder within a few seconds. You can also choose a file in Settings › Import › “Import a file”, or with the “Import a file” command in Ctrl+K.

3With Excel or another spreadsheet

  • One sheet per type, named “Tasks”, “Events”, “Obligations”, “Notes”, “Habits”, “Contacts”, “Expenses” or “Lists”.
  • First row: the column names. After that, one row per item.
  • Only the title is required (the name of a habit; the first name, last name or company of a contact), together with the date of an event, the due date of an obligation, the date and amount of a transaction, and the list of a list item. Leave unused cells empty.
  • The columns can be in any order. Unknown columns are ignored. Capital letters and accents make no difference.
  • CSV file: one type per file, recognised from its name (tasks.csv) or its columns. A “Type” column (Task, Event, Obligation, Note, Habit, Contact, Expense, Income, List) lets you mix types. Separator ; or ,.
  • Column names and values can be written in English or in French.

5Accepted values

Dates
Day first, then month: 03/10/2026, 3/10/26, 2026-10-03, 3 October 2026. Without a year (03/10): the next such date. Also: today, tomorrow, Monday, in 3 days. Dates entered as dates in Excel are recognised.
Times
14:00, 2pm, 2:30pm, noon. Time slot: 09:30-10:00.
Durations and reminders
15 min, 1 h, 1 h 30, 2 days. For a reminder, also on time or none. When no reminder is given, the default reminder (Settings › Reminders) applies to items with a set time.
Repeats
every day, every 2 days, weekdays, every Monday, every Monday and Thursday, every week, every 2 weeks, every month, every 3 months, the first Monday of the month, every year. For a task, also 3 days after completion.
Habit frequencies
every day, 3 times a week, Mon, Wed, Fri, Tuesday and Thursday, weekdays, weekends.
Birthdays
14/05/1990, 1990-05-14, 14 May 1990; without the year: 14/05, 14 May.
Amounts
312, 45.90, €1,234.50. For a transaction, also -42.50.
Tags
Letters, numbers, -, _ and /; 40 characters and 20 tags at most.
Spaces and notebooks
Their name in Aqueli. An unknown name is flagged in the preview; the item then goes to the space shown, or to the first one.
Yes or no
yes, no, x for yes.

6With a text file

A .txt or .md file contains one item per line: its type, then its fields separated by |. The first field is the title.

TASK | Call the garage | 03/10/2026 14:00 | #car | !high | space: Personal
EVENT | Dentist | 08/10/2026 09:30-10:00 | location: Martin surgery
OBLIGATION | Home insurance | due 15/11/2026 | cancel by 15/10/2026 | €312 | yearly
NOTE | Gift ideas | Cookbook, scarf
HABIT | Read | Mon, Wed, Fri | 20 pages | reminder: 21:30
CONTACT | Lea Bernard | 07700 900123 | lea.bernard@example.com | birthday: 14/05/2016
EXPENSE | €42.50 | Groceries | 27/09/2026
INCOME | September salary | €2,450 | Salary | 01/10/2026
LIST | Milk | Shopping | Fresh
  • Types: TASK, EVENT (or APPOINTMENT), OBLIGATION (or BILL), NOTE, HABIT, CONTACT, EXPENSE, INCOME, LIST.
  • For an expense or income, the title can be the amount; the date, amount and category are recognised on their own. For a list item, the field after the title is the list, then the aisle.
  • Dates, times, #tags, priorities (!high, !medium, !low), amounts, frequencies, categories and repeats are recognised on their own; for a habit, the frequency, the target (20 pages) and the reminder time; for a contact, the phone numbers, email addresses and date of birth.
  • Other fields are written name: value, using the column names: location: Martin surgery, space: Work, reminder: 1 h, subtasks: Kitchen; Living room. A field that is not recognised goes into the item's notes.
  • A line without a type is a task, written as in quick add: Call the garage tomorrow 2pm #car !high. Bullets (-, *, 1.) and checkboxes (- [ ]) at the start of a line are accepted.
  • Empty lines, headings (# Heading) and lines that start with // are ignored.
  • A .md file without types becomes a single note: the first heading (# Heading) is its title, otherwise the file name. The formatting is kept: headings, lists, checkboxes, quotes, code blocks, **bold**, *italic*, ~~strikethrough~~, ==highlight== and `code`. A note exported from Aqueli as Markdown can be imported again this way. In the preview, a file without types can also be read as a list of tasks, of events, or as a single note.

7Calendars and contacts

  • A calendar file .ics (exported from Outlook, Google Calendar or Apple Calendar) becomes events: title, dates and times, location, description, repeat and reminder.
  • A contacts file .vcf (exported from a phone, Gmail or Outlook) becomes contacts: name, company, numbers, email addresses, address, birthday, notes and tags.
  • Times written in universal time are converted to the time on this PC. A repeat that is too unusual is not carried over: the preview flags it, and you can then set it in the calendar.
  • Cancelled events and contact photos are not imported.

8Preview, errors and duplicates

  • Each row appears in the preview before the import. Nothing is added before you click “Import”.
  • A row with an error is shown in red, with the explanation. It is not imported: correct the file, then import it again.
  • A duplicate has the same type, title and date (the same name for a habit or a contact) as an item in Aqueli or an earlier row; for a transaction, also the same amount; for a list item, the same list. It is unticked; ticking it imports it anyway.
  • Unticking a row leaves it out of the import. The “Content” menu changes the type of a sheet or a file.
  • After the import, “Undo” or Ctrl+Z removes all the imported items at once.

Updating existing items

  • Tables exported by Aqueli (tasks, contacts, budget transactions) have a last column ID; exported .ics and .vcf files carry it too. Do not change it.
  • When imported again, the file updates the items that carry this ID instead of creating new ones: the row is marked “Update of an existing item.”. Before the import, a window lists the items that will be replaced and asks you to confirm.
  • What the file does not describe is kept: colour, project and ticked subtasks of a task; photo, category and card of a contact; occurrences removed from a series of events.
  • A row without an ID, or whose ID does not exist in this account (a file from another PC), creates a new item.
  • “Undo”, after the import, also restores the previous values of the updated items.

9Good to know

  • A file dropped into the Import folder is deleted after the import, because this folder is not encrypted. To keep it in Import\Traités instead: Settings › Import › “After the import”. A file dragged onto the window or chosen elsewhere stays where it is.
  • 10 MB and 5,000 items at most per file.
  • Excel: formulas are not recalculated, the last saved value is read; macros are never run.
  • Workbooks in .xls format and workbooks protected by a password cannot be read: save them in .xlsx format, without a password.
